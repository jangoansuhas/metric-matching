## Industrial Track route, with an explicit stopping rule

The SANER Industrial Track accepts full papers that systematically investigate an industrially relevant problem in real-world applications and evaluates industrial relevance, originality, soundness and practical validation. Its call allows practitioner-driven submissions to focus on specific cases without the same generalizability expectation as research-driven papers. The call does **not** require privately owned data. That leaves a possible **public-only industrial case study** if the selected repositories are genuinely used in practice and the study measures maintenance decisions on their actual definitions and commits. A collection of synthetic fixtures plus public benchmark rows, without independently reviewed real maintenance cases, is a weak full-paper submission. This is our inference from the venue criteria, not an acceptance prediction.

For a credible public-only full paper, complete at least the following before claiming findings:

1. Freeze the generic extractor and eligible scalar-definition rule on development data, verify real compiled provenance where available, and give full-context AST/lineage, constraint-aware, proposed, and feasible context-matched LLM methods the same source packet and pair frame. Report parser/coverage failures.
2. Apply the existing metadata manifest and precommitted hash-selection/eligibility process; inspect only the selected pinned public source thereafter. Keep a log of excluded or inaccessible projects and any declared practitioner-use evidence.
3. Have two independent qualified humans judge public metric pairs and commit events without seeing method predictions; use a separate adjudicator. Record comparison scope and conditional prerequisites. An author decision or AI review is not human gold. If complete anchor universes are unaffordable, report judged-pool retrieval rather than exact Recall@k.
4. Compare methods on the same held-out pairs at fixed input and review budgets. Report unsafe equivalence assertions, abstention/coverage, candidate retrieval, version-change explanations, runtime and reviewer minutes. Any practitioner-effort benefit requires an actual task-based human study; a dependency path alone is only a potential impact.
5. Document project provenance and real-world relevance. If the selected projects are only demos, labels cannot be resolved, or method coverage is too low, **do not claim industrial effectiveness**. Reframe as a public benchmark/methodology or Stage 1 study plan and choose an appropriate track.

The mandatory Industrial Track abstract is due **October 19, 2026**, and the full paper **October 23, 2026**, AoE, per the official call. Set an internal **October 12** evidence review: if a frozen public test frame, independent review capacity, runnable comparisons, and a credible industrial-practice case are not in hand, do not rush a full Industrial submission. A two-page Industrial Track talk proposal is possible but is not published in the proceedings. The Registered Report Stage 1 remains a separate plan-first route with different publication status; it is not a backdoor industrial-results claim.

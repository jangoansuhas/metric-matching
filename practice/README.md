**Do this round first, before SETUP.md.** It needs no installation: the packet's links open the pinned files on GitHub. SETUP.md's example queries show values for some of these metrics, so send your practice worksheet before you start SETUP.md.

The file is the calibration packet exactly as it was first given to reviewers, unchanged. Every practice reviewer must see the same packet, so:

- **Follow the packet's own instructions.** Where they differ from [REVIEWER_GUIDE.md](../REVIEWER_GUIDE.md), the packet wins for this round.

  - **Worksheet.** Use the worksheet table inside the packet, not `templates/REVIEWER_WORKSHEET.md`. Make a private copy of the packet, fill in the "Independent reviewer worksheet" section, and email it to the coordinator.
- **Skip the "Coordinator timing and lock log" section.** It's for the coordinator.
- **The held-out packets are different.** They use REVIEWER_GUIDE.md, the worksheet template, and a stated comparison scope for each pair.
